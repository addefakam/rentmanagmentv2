# Residential House Rent Control and Administration System

Implementation of **Ethiopia's Proclamation No. 1320/2016** (Residential House Rent Control and Administration), the **Addis Ababa City Directive No. 7/2016**, and the annexed **Model Rental Agreement** — delivered as a runnable, trilingual platform with a fully evidenced, phase-gated SDLC record.

> **Status: CLOSED & OPERATIONAL.** All ten stage gates (G0–G9) approved by the owner. Closure minute CM-P8-G9-01 signed under written decision reference GATE-G9-2026-09-11. Wave 1 (Bole sub-city, 14 woredas) live; the standing service runs under Operations Manual v1.1 / Runbook v1.1.

## What the platform enforces (law as software)

| Legal requirement | Where it lives |
|---|---|
| Written, certified, registered contracts (Proc. Art. 4) | Registration workflow with acceptance refusals |
| Minimum two-year term (Art. 6) | Rule-engine gate on contract creation |
| Annual rent adjustment — published June 1, effective June 30 (Art. 8) | Real adjustment services with legal date anchoring |
| Exemption clock for new builds (Art. 10) | Automated entitlement + expiry |
| Two-month prepaid-rent ceiling (Art. 12) | Validation with article-cited refusals |
| Electronic payment only + 10% cash-referral duty (Art. 13 / Dir. Art. 22) | Payment ledger + reconciliation |
| Dispute chain: 30 working days → 15-day appeal → committee → court (Arts. 20–26) | Timed case workflow with clock gates |
| Penalty ladder (Proclamation + Directive fine schedule) | Configurable PEN-* parameters, referral register, court-recovery tracking |
| Directive Art. 8(2) legacy-contract annotation | Migration register reconciled woreda by woreda |
| Public awareness duties (Arts. 14/16) | Trilingual awareness-material register |
| Directive Art. 13 national data feed | Monthly, hash-verified, immutable periods |

## Key characteristics

- **Trilingual console (CR-01 / NFR-06):** Amharic, English, Afan Oromo — with English fallback for uncertified legal terminology.
- **Three-tier administration:** Ministry → Bureau → Sub-city → Woreda (131 seeded organization units, 118 woredas).
- **Legal gates behave as law:** the platform *refuses* unlawful actions and cites the article it protects in the refusal.
- **Evidence discipline:** append-only registers, hash-chained audit log (814+ events, verified intact), immutable reconciliation reports.
- **Production-grade authentication:** session layer binding officer sign-in to the identity provider with capability-matrix read authorization (armed at cutover per runbook).

## Stack

- **Next.js 16** (App Router) + TypeScript
- **Prisma ORM** over SQLite (`db/custom.db`, regenerated by seed)
- Domain layer under `src/lib/domain/` — one module per phase (registrations, adjustments, disputes, penalties, migration, go-live, operations)
- Role/Capability security model under `src/lib/security/`

## Quick start (local, SQLite)

```bash
npm install                # or bun install / pnpm install
cp .env.example .env       # local SQLite URL (default)
npm run db:push            # create the schema
npm run db:seed            # seed catalogs + shipped operational state
npm run dev                # http://localhost:3000
```

**Deploying to Vercel + Neon Postgres?** See [DEPLOYMENT.md](./DEPLOYMENT.md) — the build is
database-aware (`scripts/build.mjs` selects the Prisma schema from `DATABASE_URL`).
